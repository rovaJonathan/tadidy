# TAD-018 — Tray menu actions: preferences, clear history, about, quit

> Phase 1 · P0 · full

## Context

TAD-003 built the native tray menu with only Quit wired. This ticket wires the other MVP items (MNU-03): open the preferences, clear the history with the mandatory confirmation and its "keep pinned" option (HIS-06), and the native about panel.

## Scope

- `tray.rs`: enable and handle the items:
  - `preferences` → `windows::open_preferences(app)` (TAD-017);
  - `clear-history` → show the popover (same path as a tray click, without the toggle), then emit `menu://clear-history` (no payload);
  - `about` → replaced by `PredefinedMenuItem::about` with `AboutMetadata` (name, version, copyright from `Info.plist`), label verbatim from the prototype;
  - `check-updates` → stays disabled until the P2 updater ticket (SYS-04);
  - `quit` → unchanged.
- Event `menu://clear-history`: constant in `events.rs`; added to the Events row of AGENTS.md §3 and to the events list of `docs/spec/04-architecture.md#ipc` (anchors unchanged, `spec.html` rebuilt); wrapper `onClearHistoryRequested(cb)`.
- `src/lib/components/ClearHistoryDialog.svelte`: `#dialog-clear-history` (`role="alertdialog"`), `#chk-keep-pinned` checked by default, texts and buttons verbatim from the prototype, the clip count in its text taken from the history total (`total` of `listClips({ limit: 1 })`, in the prototype's wording); confirm → `clearHistory(keepPinned)`; cancel or `Esc` → closes the dialog only. Mounted in `src/windows/Popover.svelte`, opened on `menu://clear-history`.
- The popover's focus-loss hide closes the dialog with it (nothing is cleared).

## Out of scope

- "Clear history…" in the Storage & Privacy tab (phase 2); the updater (P2).
- Any change to the menu labels or order (prototype `#tray-menu`).

## Acceptance criteria

- [ ] Given the tray menu, then Preferences…, Clear history…, About and Quit are enabled, Check for updates… is disabled, labels and order match `#tray-menu`.
- [ ] Given Preferences… is chosen, then the preferences window opens focused.
- [ ] Given Clear history… is chosen, then the popover opens with `#dialog-clear-history` shown and `#chk-keep-pinned` checked.
- [ ] Given the dialog confirmed with the box checked, then `clear_history(true)` is invoked; unchecked, `clear_history(false)`; then the list shows `#empty-history` when nothing is left.
- [ ] Given the dialog cancelled or `Esc`, then `clear_history` is not invoked and the popover stays open.
- [ ] Given About is chosen, then the native about panel shows the name, the version and the copyright, in front of other windows.
- [ ] Given Quit Tadidy, then the process exits.
