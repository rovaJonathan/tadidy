# TAD-001 — Scaffold the Tauri 2 + Svelte 5 app and its quality toolchain

> Phase 0 · P0 · repo

## Context

Nothing can be built, tested or gated until the app skeleton exists. This ticket creates the Tauri 2 shell, the Svelte 5 front, every quality tool used by `scripts/check.sh`, and the typed IPC contract (`ts-rs` bindings + `src/lib/api.ts`) with one real command proving the round trip. Every other ticket starts from here.

## Scope

- Root `package.json` with `packageManager` (pnpm 10), Node from `.nvmrc`; scripts `dev`, `build`, `tauri`, `lint`, `format`, `typecheck`, `test`, `test:cov`, `e2e`.
- Vite + Svelte 5 (runes) + TypeScript strict (`strict`, `noUncheckedIndexedAccess`); ESLint (flat config, `eslint-plugin-svelte`, `typescript-eslint`) + Prettier (`prettier-plugin-svelte`) + `svelte-check`.
- Vitest + `@testing-library/svelte` + jsdom, IPC mocked with `@tauri-apps/api/mocks` (`mockIPC`, `clearMocks` in `src/test/setup.ts`); coverage with `@vitest/coverage-v8`, LCOV written to `coverage/front/lcov.info` (not `coverage/`, which also holds `coverage/rust.lcov`).
- Playwright (Chromium only) against the Vite dev server, IPC mocked by `e2e/support/mock-ipc.ts` (injects `window.__TAURI_INTERNALS__` with `page.addInitScript`).
- A dev harness page `index.html` → `src/main.ts` → `src/App.svelte` (shows "Tadidy" and the version from `app_version`); later UI tickets mount components there for end-to-end tests.
- `src-tauri/` crate: `[lints]` in `Cargo.toml` (`unsafe_code = "deny"`, `clippy::unwrap_used`, `clippy::expect_used`, `clippy::undocumented_unsafe_blocks` denied; `clippy.toml` allows unwrap/expect in tests), `src/macos/mod.rs` as the only module with `#![allow(unsafe_code)]`.
- `tauri.conf.json`: identifier `app.tadidy`, product name `Tadidy`, `app.windows: []` (no default window), `app.macOSPrivateApi: true`, bundle target macOS 13.0; `src-tauri/Info.plist` with `LSUIElement = true`; activation policy `Accessory` set in `setup` (MNU-06); `capabilities/default.json` granting only `core:event:default`.
- Shared Rust modules: `error.rs` (`AppError { code, message }`, `#[derive(TS)]`, serializes as `{ code, message }`, never clip content or a home path), `events.rs` (constants `CLIPS_CHANGED`, `SETTINGS_CHANGED`, `ACCESSIBILITY_CHANGED`, `PANEL_SHOWN`; trait `EventSink { fn emit(&self, event: &'static str, payload: serde_json::Value) }` with `TauriEventSink` and the test fake `RecordingEventSink`), `state.rs` (empty `AppState` managed by Tauri; later tickets add fields), `commands.rs`.
- `ts-rs` exports to `src/lib/bindings/` via `src-tauri/.cargo/config.toml` (`TS_RS_EXPORT_DIR`); bindings are regenerated by `cargo test` and committed; the drift step of `scripts/check.sh` fails when they change.
- First command `app_version() -> String` and its wrapper `appVersion()` in `src/lib/api.ts`.
- Make every step of `scripts/check.sh` run for real (none skipped because a file is missing).

## Out of scope

- Tray, windows, plugins (TAD-003, TAD-006), database (TAD-007), signing (TAD-008), the coverage gate script (TAD-002).
- `DESIGN.md` tokens in CSS (TAD-003).

## Acceptance criteria

- [ ] Given a fresh clone with `pnpm install`, when `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:cov` and `pnpm e2e` run, then each exits 0.
- [ ] Given the Rust crate, when `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings` runs, then it exits 0, and an `unwrap()` added outside tests makes it fail.
- [ ] Given the front, when the dev harness calls `appVersion()`, then it receives the crate version through the `app_version` command.
- [ ] Given `AppError` changes in Rust, when `cargo test` runs without committing the regenerated file, then the bindings step of `scripts/check.sh` fails.
- [ ] Given `pnpm tauri dev`, when the app starts, then no window opens and no icon appears in the Dock or in `⌘Tab`.
- [ ] Given `pnpm test:cov` after `cargo llvm-cov --lcov --output-path coverage/rust.lcov`, when both finish, then `coverage/rust.lcov` and `coverage/front/lcov.info` both exist.

## IPC

- `app_version() -> String` · wrapper `appVersion(): Promise<string>`.
- Error shape for every later command: `AppError { code: string; message: string }` (`src/lib/bindings/AppError.ts`).

## Dependencies

- Rust: `tauri` (2, features `tray-icon`, `macos-private-api`), `tauri-build`, `serde`, `serde_json`, `thiserror`, `anyhow`, `tracing`, `tracing-subscriber`, `ts-rs`.
- npm: `svelte`, `@sveltejs/vite-plugin-svelte`, `vite`, `typescript`, `@tauri-apps/api`, `@tauri-apps/cli`, `svelte-check`, `eslint`, `typescript-eslint`, `eslint-plugin-svelte`, `prettier`, `prettier-plugin-svelte`, `vitest`, `@vitest/coverage-v8`, `jsdom`, `@testing-library/svelte`, `@testing-library/jest-dom`, `@playwright/test`.

## Security

- The capability grants `core:event:default` only; no shell, fs or http permission.
- `AppError` messages never contain clip content or an absolute path under the user's home.

## Risks

- Vitest's coverage run cleans its reports directory and would delete `coverage/rust.lcov` → write the front report to `coverage/front/`.
- `cargo add tauri` could pick a pre-release major → `cargo add tauri@2`, and keep `@tauri-apps/api` / `@tauri-apps/cli` on the same major and minor as the crate (AGENTS.md §2).
- `@tauri-apps/api/mocks` does not cover Playwright → `e2e/support/mock-ipc.ts` injects the same `__TAURI_INTERNALS__` shape in the page.
