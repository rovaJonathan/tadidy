# TAD-013 — Clip browser: search bar, list, rows and empty states

> Phase 1 · P0 · ui

## Context

The clip browser is the one component the user sees every day, shared by the popover and the Quick Panel (QPN-06, hosted in TAD-016). This ticket builds its read side: search, a virtualized newest-first list with rich rows, the clip count and the two empty states, updated live when the watcher records a clip.

## Scope

- `src/lib/stores/clips.svelte.ts`: `ClipsStore` class with runes — `search`, `items`, `total`, `nextCursor`, `loading`, `selectedIndex`; `setSearch(text)` debounced 50 ms (SRC-01); `loadMore()`; `refresh()` (first page, keeps the selected id when still present); subscribes to `onClipsChanged` and refreshes; `reset()` (empty search, selection 0, refresh).
- `src/lib/components/ClipBrowser.svelte`: composes the parts below; owns one `ClipsStore`.
- `SearchBar.svelte`: `#search-input`, placeholder and shortcut hint verbatim from the prototype, focused on mount.
- `ClipList.svelte`: `#clip-list`, `role="listbox"`, virtualized with fixed row height (only the visible rows + overscan in the DOM, about 30 nodes), loads the next page when the last 10 rows become visible.
- `src/lib/virtual-list.ts`: pure `visibleRange(scrollTop, viewportHeight, rowHeight, count, overscan)`.
- `ClipRow.svelte`: `.clip-row`, `role="option"`, `aria-selected`; `⌘1`…`⌘9` badge on the first nine rows (display only), kind icon per `ClipKind`, 2-line preview (CSS line clamp), source app icon (from `getAppIcon`, cached per bundle id as an object URL, generic icon when absent), relative time.
- `src/lib/format.ts`: `relativeTime(ms, now)` in the prototype's format; the rows refresh it every minute; `clipCountLabel(total)`.
- `BrowserFooter.svelte`: `#clip-count` (TAD-016 adds `#btn-preferences`).
- `EmptyState.svelte`: `#empty-history` (no clip at all) and `#empty-search` (search with no result, quoting the search), texts verbatim from the prototype.
- Styles from `src/styles/tokens.css` only; the selected row uses the accent token.
- Mounted in the dev harness `src/App.svelte` for end-to-end tests (TAD-016 mounts it in the real windows).

## Out of scope

- Keyboard navigation, paste, copy, delete (TAD-014, TAD-015); tabs `#tab-all`/`#tab-pinned`/`#tab-snippets` and kind filters (P1, SRC-03); hover quick actions and context menu (P1/P2); preview (QPN-05, P1); term highlighting (SRC-02, P1).
- `⌘1`–`⌘9` key handling (PST-04, P1): the badge is displayed only.
- The Accessibility banner (TAD-015) and `#btn-preferences` (TAD-016).

## Acceptance criteria

- [x] Given 3 clips, when the browser mounts, then 3 `.clip-row` appear newest first, each with its badge, kind icon, 2-line preview, app icon and relative time, and `#clip-count` shows the prototype's text for 3.
- [x] Given typing "sel" quickly, then `list_clips` is invoked once, 50 ms after the last key, with `{ search: "sel" }`.
- [x] Given a search with no result, then `#empty-search` shows the prototype text with the search quoted; given no clip at all, then `#empty-history` is shown.
- [x] Given 1 000 clips, then at most about 30 `.clip-row` elements are in the DOM, and scrolling to the end loads the next page with the cursor.
- [x] Given a `clips://changed` event, then the first page is reloaded and the new clip appears at the top without user action.
- [x] Given a bundle id without an icon, then the row shows the generic icon and `getAppIcon` is invoked once per bundle id.
- [x] Given the list, then it has `role="listbox"` with rows `role="option"` and `aria-selected` on the selected row.
- [x] Given the prototype, then every text, id and state listed in `prototype` matches (`prototype-parity`).
