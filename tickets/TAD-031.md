# TAD-031 — Replace the hard-coded focus ring width and pressed brightness with tokens

> Phase 1 · P2 · ui · Discovered in: TAD-022 (review of the pull request)

## Context

AGENTS.md §14 says styles use the DESIGN.md tokens, with no hard-coded sizes. Two literals are repeated across the front: `outline: 3px solid var(--color-focus-ring)` (the ring width, written in DESIGN.md §5 as a literal) in about a dozen components and `src/styles/preferences.css`, and `filter: brightness(0.92)` (the pressed state of the primary button) in the three confirmation dialogs. TAD-022 added a third dialog and an empty-state button that follow the same pattern as the existing ones, so fixing it in those files only would make them differ from their neighbours.

## Scope

- Two tokens in `src/styles/tokens.css` and DESIGN.md (`--focus-ring-width`, `--pressed-brightness`), and every existing literal replaced by them.
- DESIGN.md §5 and the UI checklist mention the tokens instead of the literals.

## Out of scope

- Any visual change: the values stay 3 px and 0.92.
- Other literals (colors, durations) not named above.

## Steps

- [ ] Red test: a script or unit test that fails while `outline: 3px` or `brightness(0.92)` appears outside `tokens.css`.
- [ ] Add the tokens; replace the literals; update DESIGN.md.
- [ ] Open the pull request to `main`.
