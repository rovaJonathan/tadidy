# TAD-029 — Retry opening the history database when the failure may be temporary

> Phase 1 · P1 · full · Discovered in: TAD-022 (second review of the pull request)

## Context

TAD-022 never offers the reset for a failure that may be temporary (a locked Keychain, a denied prompt: `canReset` is `false`), because a reset would throw away a history that is only out of reach. But nothing retries the open either: the user unlocks the Keychain and the window still says "Your history can’t be opened" until the app is relaunched. The core already knows how to open the database again (`reset_history` does it first), but only a reset can trigger it, and that button is hidden in exactly this case.

## Decision (owner, 2026-11-02)

The prototype has no such state, so the interface was the owner's call. Chosen: **option 1, retry on show**. Option 2 is kept below for the record.

1. **Retry on show** (chosen): the core opens the database again whenever the popover or the Quick Panel is shown while the status is `unavailable` and not resettable. No new text, no new button.
2. **A *Try again* button** (not chosen) in the error state for temporary failures, with agreed copy; it retries the open and never resets.

## Scope

- A core command (or the existing status call) that retries the open only, attaches the history on success (watcher, settings, shortcut, login item as `reset_history` does) and announces `storage://changed` and `clips://changed`.
- The trigger in the front: a retry when the popover or the Quick Panel is shown (`panel://shown`), no new text and no new button.

## Out of scope

- Resetting for a temporary failure; any recovery from the `.bak` files.

## Acceptance criteria

- [ ] Given a failure that may be temporary, when the Keychain works again and the trigger fires, then the history opens without a restart and the windows update.
- [ ] Given the failure persists, when the trigger fires, then nothing is moved and the error state stays.
- [ ] Given a retry, then it never resets: no `.bak` file is created and the Keychain key is not written.
