# TAD-006 — Non-activating Quick Panel and global shortcut

> Phase 0 · P0 · full

## Context

Phase 0 spike "non-activating NSPanel" — the highest risk of the spec: if the panel steals focus, `⌘V` lands in the wrong app. The Quick Panel must take keyboard input while the target app stays active, on every Space and above full-screen apps. It hosts the clip browser in TAD-016.

## Scope

- Window label `panel`, `panel.html` → `src/windows/panel.ts` → `src/windows/Panel.svelte` (placeholder content until TAD-016), size from the prototype `#quick-panel`, created hidden in `setup`.
- `src-tauri/src/macos/panel.rs`: converts the window with `tauri-nspanel`: style `nonactivatingPanel`, level `floating`, collection behaviour `canJoinAllSpaces` + `fullScreenAuxiliary`, `canBecomeKeyWindow = true`; `show_panel` (order front + make key, **without** activating the app), `hide_panel`, `is_panel_visible`; hides when the panel resigns key (click elsewhere).
- Placement: centered on the screen that contains the mouse pointer; pure `windows::center_in(screen: Rect, size: Size) -> Position` (QPN-03 options are P1).
- `src-tauri/src/shortcuts.rs`: `tauri-plugin-global-shortcut` (Rust side only); `DEFAULT_QUICK_PANEL_SHORTCUT = "Cmd+Shift+V"`; `register_quick_panel(app, accelerator) -> Result<(), ShortcutError>` with `ShortcutError::Invalid(String)` and `ShortcutError::Unavailable(String)`; on `Pressed`, `windows::toggle_panel`.
- `ShortcutStatus { accelerator: String, error: Option<String> }` (ts-rs) kept in `AppState`; a startup registration failure is logged (code only) and stored there for the preferences (TAD-017). The app keeps running without the shortcut.
- Event `panel://shown` with payload `PanelShown { window: String }` (ts-rs), emitted after the Quick Panel **and** the popover are shown; wrapper `onPanelShown(cb)` in `src/lib/api.ts`.
- `hide_window` (TAD-003) also hides the Quick Panel when called from it; `Esc` in `Panel.svelte` calls `hideWindow()`.

## Out of scope

- The clip browser in the panel (TAD-016); positioning options (QPN-03, P1); changing the shortcut (TAD-017).
- Pasting from the panel (TAD-015).

## Risks

- The panel takes focus and the target app deactivates → nonactivating style mask before the first show; show with order-front + make-key, never `set_focus()` (which activates the app).
- The webview gets no keyboard input in a non-key panel → `canBecomeKeyWindow = true` and make it key on show.
- `tauri-nspanel` may not be published on crates.io → if `cargo info tauri-nspanel` finds no stable release, depend on the upstream git repository at its latest release tag (never a moving branch) and record it in `docs/reference.md` and `PROGRESS.md`.
- `⌘⇧V` already used by another app → typed error kept in `ShortcutStatus`, shown by the preferences (TAD-017).
