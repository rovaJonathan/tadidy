# TAD-002 — Coverage gate on changed files

> Phase 0 · P0 · repo

## Context

AGENTS.md §9 requires ≥ 80 % line coverage on every changed file, Rust and front. There is no CI (ADR 0004), so the `pre-push` hook must enforce it locally. `scripts/check.sh --cov` already produces the LCOV reports and calls `node scripts/coverage-changed.mjs` when it exists: this ticket writes that script.

## Scope

- `scripts/coverage-changed.mjs` (no dependency, `node:` modules only):
  - reads LCOV files, default `coverage/rust.lcov` (from `cargo llvm-cov --lcov`) and `coverage/front/lcov.info` (from `pnpm test:cov`), overridable with `--lcov <path>` (repeatable);
  - normalizes `SF:` paths (absolute or relative) to paths relative to the repository root;
  - lists the changed files with `git diff --name-only --diff-filter=AMR <merge-base>` where `<merge-base>` = `git merge-base HEAD main` (`--base <ref>` to override); working-tree changes are included;
  - keeps only source files: `src-tauri/src/**/*.rs`, `src/**/*.ts`, `src/**/*.svelte`;
  - excludes `src-tauri/src/macos/**` (AGENTS.md §9), `src-tauri/src/main.rs`, `src/lib/bindings/**` (generated), `**/*.test.ts`, `src/test/**`, `e2e/**`, `src-tauri/tests/**`, `*.d.ts`; the exclusion list is one exported constant;
  - a changed source file absent from every report counts as 0 %;
  - prints one line per checked file (`path  lines-hit/lines-found  pct`) and exits 1 when any file is below `--min` (default 80);
  - exits 0 with a message when no source file changed.
- Pure functions exported for tests: `parseLcov(text)`, `normalizePath(path, root)`, `isGated(path)`, `evaluate(changed, coverage, min)`.
- `scripts/check.sh` and `lefthook.yml`: confirm `check.sh --cov` runs the script and the `pre-push` hook calls `scripts/check.sh --cov`; adjust only if a path differs.

## Out of scope

- Branch or function coverage (lines only).
- Changing the 80 % threshold or the coverage tools configured by TAD-001.

## Acceptance criteria

- [x] Given an LCOV record with `LF:10` and `LH:8` for a changed `src-tauri/src/watcher.rs`, when the gate evaluates it, then the file passes at 80 %.
- [x] Given `LF:10` and `LH:7` for a changed file, when the gate runs, then it prints the file with 70 % and exits 1.
- [x] Given a changed `src-tauri/src/macos/pasteboard.rs`, `src/lib/bindings/Settings.ts`, `src/lib/api.test.ts` or `e2e/smoke.spec.ts`, when the gate runs, then the file is not checked.
- [x] Given a changed `src/lib/keyboard.ts` missing from both reports, when the gate runs, then it is reported at 0 % and the gate fails.
- [x] Given an `SF:` line with an absolute path inside the repository, when it is parsed, then it matches the relative path from `git diff`.
- [x] Given no changed source file, when the gate runs, then it prints "no changed source file" and exits 0.
- [x] Given a push, when the `pre-push` hook runs, then `scripts/check.sh --cov` runs the gate.

## Tests

**Unit** — `scripts/coverage-changed.test.mjs`: `parseLcov` (several records, `SF`/`LF`/`LH`/`DA`), `normalizePath`, `isGated` (each exclusion), `evaluate` (pass, fail, missing file, empty list).
**Integration** — one test runs the CLI in a temporary git repository (`git init`, a `main` commit, a branch changing one file, a fixture LCOV) and checks the exit code.
**UI / end-to-end** — none.
**Manual** — none.

## Verification

- `node --test scripts/coverage-changed.test.mjs` → all pass
- `scripts/check.sh --cov` → the "Coverage ≥ 80 % on changed files" step runs and passes on this branch
- `scripts/check.sh` → exit 0

## Security

- The script reads only LCOV files and `git` output; it writes nothing and makes no network call.

## Risks

- `cargo llvm-cov` writes absolute `SF:` paths while Vitest writes relative ones → normalize both against the repository root.
- Files that only wire Tauri (`lib.rs`) can fall under 80 % → keep logic out of them (AGENTS.md §13) and test it where it lives; do not grow the exclusion list without a line in `PROGRESS.md`.
- Svelte files missing from the front report because Vitest only reports imported files → set `coverage.include` to `src/**/*.{ts,svelte}` in `vite.config.ts` if TAD-001 did not.
