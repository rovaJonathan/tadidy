# TAD-000 — Set up the development environment

> Phase 0 · P0 · repo · Bootstrap ticket: committed directly as the first commit of `main` (no remote, nothing to open a pull request against).

## Context

Before any app code, the repository needs the working contract, the tracking, the quality gate and the reference documents that every later ticket relies on. Modelled on the fluent-test repository, without Linear and without a review bot.

## Scope

- `AGENTS.md` + `CLAUDE.md`, `GLOSSARY.md`, `DESIGN.md`, `PROGRESS.md`, `README.md`.
- The English spec split in `docs/spec/` with stable anchors and its HTML build (`scripts/spec/`); the French draft archived.
- The clickable prototype `docs/prototype/prototype.html`.
- Tickets as markdown (`tickets/`, `scripts/tickets.mjs` + tests, `docs/guides/tickets.md`) and the phase 0 + MVP backlog TAD-001…TAD-019.
- Local gate: `lefthook.yml`, `scripts/check.sh`, `scripts/commit-msg.mjs`, `scripts/repo-check.mjs`, `scripts/pre-push-guard.sh` (+ tests); gitleaks, cargo-llvm-cov installed.
- ADRs 0001–0006, `docs/reference.md`, manual QA guide, signing runbook, pull request template, `.claude/settings.json` and the project skills.

## Out of scope

- Any app code (TAD-001).
- The GitHub repository and its remote (created by the owner).
- The coverage gate script (TAD-002).
