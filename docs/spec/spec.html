Tadidy — Specification

Tadidy (“to remember” in Malagasy) is a clipboard history manager for macOS that lives in the menu bar, inspired by CopyClip and CopyClip 2.

Document version 0.2 — 2026-10-28
Platform macOS 13 Ventura and later, Apple Silicon + Intel (universal binary)
Stack Rust (core) · Tauri 2 (shell) · Svelte 5 + TypeScript (UI) · encrypted SQLite (SQLCipher)
UI language English only
Distribution Personal use, direct DMG (outside the Mac App Store, so no sandbox)
Sync None, 100% local storage

The spec is the source of truth. Tickets cite it with docs/spec/<file>.md#<anchor>: never rename or delete an anchor a ticket cites.

Domain vocabulary lives in GLOSSARY.md.

Open questions

  1. Ignore concealed content (passwords): not checked during scoping, but included here (CAP-11), on by default and can be turned off. To be confirmed.
  2. Pause capture (“Pause for 15 min / 1 h / until resumed”): not kept for now. Add it as P2?
  3. Quick Panel position: under the mouse (proposed default) or centered?
  4. Sound or visual feedback on copy (the tray icon “pulses”): wanted?
  5. Global shortcut: is ⌘⇧V fine, or do you prefer ⌥⌘V / ⌃⌥V?
  6. Signing: do you have an Apple Developer account, or do we go with a self-signed certificate?

Overview

Problem

macOS keeps only one item on the clipboard. Copying overwrites the previous one, and the text, link or image you copied before is lost.

Goals

  1. Lose nothing: everything you copy (text, rich text, images, files, URLs) is recorded in the history automatically.
  2. Find it fast: open the history with one shortcut, type a few letters, press Return. Less than 2 seconds from need to paste.
  3. Stay out of the way: an icon in the menu bar, no icon in the Dock, near-zero CPU use when idle.
  4. Stay private: encrypted database, no data leaves the machine, old clips expire automatically.

Out of scope (v1)

  • Multi-Mac / iCloud sync
  • Mac App Store version (the sandbox prevents auto-paste)
  • Localization other than English
  • Windows / Linux (Tauri would allow it, but clipboard access and pasting are macOS-specific)

Clipboard watcher

macOS provides no notification when the clipboard changes. So we have to poll changeCount:

  1. A dedicated thread reads NSPasteboard.generalPasteboard.changeCount every 300 ms (internal setting). It is a plain integer, so the cost is negligible.
  2. If the value has changed:
    1. Read NSWorkspace.sharedWorkspace.frontmostApplication to get the bundle ID and name of the source app.
    2. If the app is excluded, ignore the change.
    3. Read the list of types. If it contains a concealed or transient type, ignore it.
    4. If it contains the internal marker app.tadidy.internal, it is a write by Tadidy: move the existing clip to the top and stop (CAP-12).
    5. Extract the useful representations in this priority order: file-url > image (png/tiff) > rtf/html > url > utf8-plain-text.
    6. Compute the hash, deduplicate, insert into the database, generate the thumbnail off the polling thread.
    7. Emit the Tauri event clips://changed to the webview.
  3. Polling is adaptive: 300 ms by default, 1 s when the session has been idle for more than 5 min (CGEventSourceSecondsSinceLastEventType), to save battery.

Paster

  1. Write all the clip’s representations to the clipboard, plus the app.tadidy.internal marker type.
  2. Hide the Quick Panel or the popover. Since the Quick Panel is a non-activating NSPanel, the target app keeps focus. The popover, on the other hand, is a real window: we must remember the active app when it opens and reactivate it with NSRunningApplication.activateWithOptions.
  3. Wait about 50 ms, then post CGEvent keyDown/keyUp V with the Command flag on kCGHIDEventTap.
  4. If AXIsProcessTrusted() returns false, stop at step 1 (copy only) and show SYS-03.
  5. “Restore previous clipboard after paste” option (P2): put the previous item back 500 ms later.

Data model (SQLite / SQLCipher)

CREATE TABLE clips (
  id              TEXT PRIMARY KEY,          -- UUID v7
  kind            TEXT NOT NULL,             -- 'text'|'rich'|'image'|'file'|'url'|'color'
  content_hash    TEXT NOT NULL UNIQUE,      -- SHA-256 of the primary representation
  plain_text      TEXT,                      -- searchable text (text, image alt, file names, URL)
  preview         TEXT,                      -- truncated preview (300 chars)
  title           TEXT,                      -- snippets
  source_bundle   TEXT,
  source_name     TEXT,
  byte_size       INTEGER NOT NULL,
  width           INTEGER, height INTEGER,   -- images
  pinned          INTEGER NOT NULL DEFAULT 0,
  pin_order       REAL,
  collection_id   TEXT REFERENCES collections(id) ON DELETE SET NULL,
  copy_count      INTEGER NOT NULL DEFAULT 1,
  created_at      INTEGER NOT NULL,          -- ms epoch, first copy
  last_copied_at  INTEGER NOT NULL,          -- main sort key
  last_used_at    INTEGER                    -- last paste from Tadidy
);
CREATE INDEX idx_clips_recent ON clips(pinned, last_copied_at DESC);
CREATE INDEX idx_clips_kind   ON clips(kind, last_copied_at DESC);
CREATE INDEX idx_clips_last_copied ON clips(last_copied_at DESC, id DESC);  -- unfiltered newest-first list, total order

CREATE TABLE representations (
  clip_id  TEXT NOT NULL REFERENCES clips(id) ON DELETE CASCADE,
  uti      TEXT NOT NULL,                    -- public.rtf, public.png, public.file-url…
  data     BLOB NOT NULL,
  PRIMARY KEY (clip_id, uti)
);

CREATE TABLE thumbnails (
  clip_id  TEXT PRIMARY KEY REFERENCES clips(id) ON DELETE CASCADE,
  png      BLOB NOT NULL
);

CREATE TABLE collections (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, sort REAL NOT NULL
);

CREATE TABLE excluded_apps (
  bundle_id TEXT PRIMARY KEY, name TEXT NOT NULL
);

CREATE TABLE settings (
  key TEXT PRIMARY KEY, value TEXT NOT NULL  -- JSON
);

CREATE TABLE app_icons (                      -- source app icon cache
  bundle_id TEXT PRIMARY KEY, png BLOB NOT NULL
);

CREATE VIRTUAL TABLE clips_fts USING fts5(
  plain_text, title, source_name,
  content='clips', content_rowid='rowid',
  tokenize='unicode61 remove_diacritics 2'
);
-- + triggers on clips keep clips_fts in sync: AFTER INSERT, AFTER DELETE, and AFTER UPDATE OF
--   plain_text, title, source_name (only when one of them changed, so a bump rewrites nothing)

Location: ~/Library/Application Support/app.tadidy/tadidy.db (+ WAL).

“Everything in the database” choice: images are stored as BLOBs in the encrypted database rather than as files. This gives a single encryption mechanism, atomic deletes and simple backups. The trade-off is that the database grows, hence the limits CAP-13 and HIS-04, and an incremental VACUUM (auto_vacuum = INCREMENTAL).

Encryption

  • The database is encrypted with SQLCipher (AES-256, PRAGMA key).
  • On first launch, a random 256-bit key is generated and stored in the macOS Keychain (kSecClassGenericPassword, service app.tadidy, accessibility AfterFirstUnlockThisDeviceOnly).
  • The key never leaves the process memory and is never logged.
  • If the key is missing while the database exists (Keychain reset), offer to reset the history. No recovery is possible.
  • The JSON export is in plain text, and the export dialog says so.
  • ⚠️ Keychain access is tied to the code signature: see Permissions, signing, distribution (stable signature).

Quality

Non-functional requirements

Category Requirement
Performance Popover / Quick Panel opens in < 100 ms (pre-created windows). Search < 50 ms over 10,000 clips. Virtualized list (only about 30 DOM nodes rendered).
Resources Idle CPU < 0.5% (adaptive polling). RAM < 120 MB (WebKit included).
Reliability No clip is lost if the app crashes: write to the database before emitting the event, WAL journal. Versioned and tested schema migrations.

Compatibility macOS 13+, universal arm64 + x86_64 binary. Works with multiple displays, Spaces and full-screen apps.
Accessibility VoiceOver on the list (listbox/option roles), full keyboard navigation, AA contrast, respects “Reduce motion” / “Reduce transparency”.

MVP acceptance criteria

  1. Copy text in any app: it appears at the top of the popover in less than 500 ms.
  2. Copy the same text twice: a single clip, moved to the top, copy_count = 2.
  3. ⌘⇧V in TextEdit, ↓, Return: the 2nd clip is pasted into TextEdit, which keeps focus.
  4. Accessibility permission revoked: Return only copies and the banner is shown.
  5. With the limit set to 10, an 11th copy deletes the oldest unpinned clip.
  6. Typing “sel” filters in less than 50 ms and shows only the clips containing “sel”.
  7. After restarting the Mac, Tadidy is running (if the option is checked) and the history is intact.
  8. Opening tadidy.db with sqlite3 without the key fails (“file is not a database”).
  9. No icon in the Dock or in ⌘Tab.
  10. Idle CPU < 0.5%, measured over 10 min in Activity Monitor.

Permissions, signing, distribution

Topic Decision
Accessibility (TCC) Required for auto-paste (CGEvent). Requested during onboarding. Without it, the app works in “copy only” mode.
Sandbox Disabled, since there is no App Store. No sandbox entitlement.
Info.plist LSUIElement = true (no Dock icon), NSHumanReadableCopyright, bundle ID app.tadidy.
Signing ⚠️ Important: macOS ties the Accessibility permission and Keychain access to the signing identity. An ad hoc signature changes on every build, so the app would have to be re-authorized every time. Solution: sign with a stable identity, either a “Developer ID Application” certificate ($99/year, which also allows notarization) or, for strictly personal use, a self-signed certificate created in Keychain Access and referenced through the APPLE_SIGNING_IDENTITY environment variable (signingIdentity stays null in tauri.conf.json, so no identity name is committed).
Notarization Optional for personal use. Required if the app is shared, to avoid being blocked by Gatekeeper.
Packaging tauri build --target universal-apple-darwin produces .app + .dmg.
Updates (P2) tauri-plugin-updater: Tauri signing key (separate from the Apple signature), latest.json published on GitHub Releases.

Risks and points of attention

Risk Impact Mitigation
The popover steals focus, and ⌘V goes to the wrong app High Quick Panel as a non-activating NSPanel. For the popover, remember the active app and reactivate it before pasting. To validate in a spike (phase 0).
Accessibility permission lost on every rebuild Medium (dev) Stable signature from day one (Permissions, signing, distribution). In dev, launch from the signed .app, not via cargo run.
Building SQLCipher (OpenSSL) as a universal binary Medium bundled-sqlcipher-vendored-openssl feature, tested in CI from phase 0.
Database growing with images Medium Size limits, quota, incremental_vacuum after purges.
Polling and battery Low Adaptive polling. Read only changeCount, never the content, as long as it does not change.
Exotic content (proprietary app formats such as Figma or Office) Low Keep only known UTIs. P2 option “keep all representations” with a size limit.
⌘⇧V shortcut already used by another app Low Detect the registration failure and report it in the preferences.
WebKit memory footprint Low Windows are hidden, not destroyed. A single webview shared by the popover and the panel is possible if needed.
