# Features

Priorities: **P0** = MVP · **P1** = v1.0 · **P2** = after v1.0 (see [Priorities](README.md#priorities)).

<a id="capture"></a>

## Clipboard capture

| ID | Feature | Prio |
|---|---|---|
| <a id="cap-01"></a>CAP-01 | Watch the general pasteboard (`NSPasteboard.generalPasteboard`) continuously, in the background. | P0 |
| <a id="cap-02"></a>CAP-02 | Capture **plain text**. | P0 |
| <a id="cap-03"></a>CAP-03 | Capture **rich text** (RTF, HTML) and also keep the plain-text version. | P1 |
| <a id="cap-04"></a>CAP-04 | Capture **images** (PNG, TIFF, JPEG, HEIC) and generate a thumbnail (max. 256 px). | P1 |
| <a id="cap-05"></a>CAP-05 | Capture **files** copied from the Finder (one or more `file-url`). | P1 |
| <a id="cap-06"></a>CAP-06 | Detect **URLs** (`public.url` type, or text that is a valid URL) and classify them as kind `url`. | P1 |
| <a id="cap-07"></a>CAP-07 | Detect **colors** (`#RRGGBB`, `rgb()`, `hsl()`) and show a swatch. | P2 |
| <a id="cap-08"></a>CAP-08 | Record the **source app**: bundle ID, name, icon (cached). | P0 |
| <a id="cap-09"></a>CAP-09 | **Deduplication**: if the content (SHA-256 hash of the primary representation) already exists, no duplicate is created. The existing clip moves to the top, with `copy_count + 1`. | P0 |
| <a id="cap-10"></a>CAP-10 | **Excluded apps**: capture nothing when the source app is on the exclusion list. Default list: 1Password, Bitwarden, Keychain Access, Passwords. | P1 |
| <a id="cap-11"></a>CAP-11 | **Concealed types**: ignore content marked `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` and `org.nspasteboard.AutoGeneratedType` (nspasteboard.org convention, used by password managers). Setting on by default. | P1 |
| <a id="cap-12"></a>CAP-12 | **Ignore own writes**: when Tadidy puts a clip back on the clipboard, it does not capture it again as a duplicate. It simply moves the existing clip to the top. | P0 |
| <a id="cap-13"></a>CAP-13 | **Size limits**: ignore text > 1 MB and images > 20 MB (configurable). | P1 |
| <a id="cap-14"></a>CAP-14 | Choose the captured types in the preferences (text / rich / images / files). | P1 |

<a id="history"></a>

## History

| ID | Feature | Prio |
|---|---|---|
| <a id="his-01"></a>HIS-01 | Show the list of clips from newest to oldest, with a preview (2 lines of text, or a thumbnail), a kind icon, the source app icon and a relative date ("3 min ago"). | P0 |
| <a id="his-02"></a>HIS-02 | **Maximum history size**: **500 clips** by default, adjustable from 10 to unlimited. Pinned clips and snippets do not count toward the limit. | P0 |
| <a id="his-03"></a>HIS-03 | **Auto-expiry**: delete clips older than *N* days (off, 1, 7, 30, 90 or 365 days). Pinned clips are never purged. The purge runs at startup, then every hour. | P1 |
| <a id="his-04"></a>HIS-04 | **Image disk quota**: 1 GB by default. Above it, the oldest unpinned images are purged. | P1 |
| <a id="his-05"></a>HIS-05 | **Delete** a clip (with a confirmation that can be turned off, as in CopyClip 1.9.84). | P0 |
| <a id="his-06"></a>HIS-06 | **Clear history**, with a "keep pinned" option checked by default and a mandatory confirmation. | P0 |
| <a id="his-07"></a>HIS-07 | **Edit** a text clip (creates a new version; the original is replaced). | P2 |
| <a id="his-08"></a>HIS-08 | Show the copy count (`copy_count`) and the last-used date in the clip detail. | P2 |

<a id="search"></a>

## Search and filters

| ID | Feature | Prio |
|---|---|---|
| <a id="src-01"></a>SRC-01 | **Instant search** as you type (50 ms debounce) over clip text, snippet titles, file names and URLs. SQLite FTS5 index. | P0 |
| <a id="src-02"></a>SRC-02 | Highlight matched terms in the preview. | P1 |
| <a id="src-03"></a>SRC-03 | **Kind filters** as chips: All · Text · Rich · Images · Files · Links. | P1 |
| <a id="src-04"></a>SRC-04 | **App filter**: `app:safari` syntax or a drop-down menu. | P2 |
| <a id="src-05"></a>SRC-05 | **Date filters**: `today`, `yesterday`, `7d`. | P2 |
| <a id="src-06"></a>SRC-06 | Fuzzy search (typo-tolerant) as a fallback when FTS5 returns nothing. | P2 |

<a id="paste"></a>

## Paste and copy

| ID | Feature | Prio |
|---|---|---|
| <a id="pst-01"></a>PST-01 | **Paste** (Return or double-click): put the clip back on the clipboard, close the panel, give focus back to the previous app, then simulate `⌘V`. Requires the **Accessibility** permission. | P0 |
| <a id="pst-02"></a>PST-02 | **Copy only** (`⌘C` or `⌥Return`): put it back on the clipboard without pasting. This is also the fallback mode when the Accessibility permission is denied. | P0 |
| <a id="pst-03"></a>PST-03 | **Paste as plain text** (`⇧Return`): strip RTF/HTML formatting. | P1 |
| <a id="pst-04"></a>PST-04 | **Quick paste**: `⌘1` to `⌘9` paste the *n*-th displayed clip directly. | P1 |
| <a id="pst-05"></a>PST-05 | Global option "Always paste as plain text". | P1 |
| <a id="pst-06"></a>PST-06 | On-the-fly **transforms** from a clip's context menu: UPPERCASE, lowercase, Title Case, trim whitespace, JSON pretty/minify, URL encode/decode, Base64 encode/decode. | P2 |
| <a id="pst-07"></a>PST-07 | **Paste many**: select several clips (`⇧`/`⌘`-click) and paste them concatenated, with an adjustable separator (newline, space, comma). | P2 |
| <a id="pst-08"></a>PST-08 | Files: pasting puts back the `file-url`s, so the file can be pasted in the Finder or into an upload field. Secondary action "Reveal in Finder". | P1 |
| <a id="pst-09"></a>PST-09 | URLs: secondary action "Open in browser" (`⌘O`). | P1 |

## Pinned clips and snippets

| ID | Feature | Prio |
|---|---|---|
| <a id="pin-01"></a>PIN-01 | **Pin / unpin** a clip (`⌘P`). Pinned clips appear in the *Pinned* tab and, depending on a setting, at the top of the *All* list. | P1 |
| <a id="pin-02"></a>PIN-02 | Reorder pinned clips by drag and drop. | P2 |
| <a id="pin-03"></a>PIN-03 | **Snippets**: give a pinned clip a title and file it in a **collection** (e.g. "Emails", "SQL", "Addresses"). | P1 |
| <a id="pin-04"></a>PIN-04 | **Create a snippet by hand** ("New snippet" button: title, text content, collection). | P1 |
| <a id="pin-05"></a>PIN-05 | Manage collections: create, rename, delete, reorder. | P1 |
| <a id="pin-06"></a>PIN-06 | **Global shortcut per snippet** (e.g. `⌃⌥1` pastes the email signature). | P2 |

<a id="quick-panel"></a>

## Quick Panel (global shortcut)

| ID | Feature | Prio |
|---|---|---|
| <a id="qpn-01"></a>QPN-01 | Configurable **global shortcut**, `⌘⇧V` by default, that opens/closes the Quick Panel. | P0 |
| <a id="qpn-02"></a>QPN-02 | The panel is a **non-activating NSPanel**: it receives keyboard input without deactivating the current app, which guarantees that `⌘V` lands in the right window. | P0 |
| <a id="qpn-03"></a>QPN-03 | Adjustable position: under the mouse pointer (default), centered on the active screen, or near the text caret (via the Accessibility API, in P2). | P1 |
| <a id="qpn-04"></a>QPN-04 | 100% keyboard navigation (see [Keyboard shortcuts](03-interface.md#keyboard-shortcuts)). Typing any character focuses the search. | P0 |
| <a id="qpn-05"></a>QPN-05 | **Preview** of the selected clip (`Space`): full text with basic syntax highlighting if it is code, large image, file list. | P1 |
| <a id="qpn-06"></a>QPN-06 | Same tabs, filters and actions as the popover (shared Svelte component). | P0 |

<a id="preferences"></a>

## Preferences

Standard window (≈ 640 × 480) with a tab sidebar.

| Tab | Settings | Prio |
|---|---|---|
| **General** | Launch at login · History size (10–∞, default 500) · Auto-expire after (off/1/7/30/90/365 days) · Confirm before delete · Show pinned on top · Play sound on copy (off) | P0/P1 |
| **Capture** | Captured types (text/rich/images/files) · Ignore concealed/transient content (on) · Max text size · Max image size · Excluded apps (list + "+" button that opens an app picker or offers the running apps) | P1 |
| **Shortcuts** | Open Quick Panel (`⌘⇧V`) · Quick paste ⌘1–9 (on/off) · Paste as plain text by default · Snippet shortcuts (P2) | P0/P1 |
| **Appearance** | Theme (System/Light/Dark) · Panel position · Preview lines (1–4) · Show app icons · Compact mode | P1 |
| **Storage & Privacy** | Database encryption status (always on) · DB / image size · Image disk quota · Clear history… · Export… / Import… (JSON, with an "export is not encrypted" warning) · Reveal data folder | P1 |
| **About** | Version, license, GitHub link, Check for updates | P1 |
