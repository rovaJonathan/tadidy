# Two display scales send a window off every display

**Symptom.** With a Retina built-in display (scale 2) and an external display at scale 1, the popover opened in the middle of a display, or not at all, and every tray click logged `could not place the popover under the tray icon error=No monitor found for the window`. It looked tied to the first launch after an install, or to the multi-display setup alone: it was neither. It came back or went away from one launch to the next, depending on where the keyboard focus was when Tadidy started.

**Cause.** tao and tray-icon report positions in pixels, each at its own scale: a monitor's position and size at that monitor's scale, the tray icon's rectangle at the scale of the menu bar's display, the cursor at the **primary** monitor's scale, and `set_position(Physical…)` converts with the scale of the display the **window** is on at that moment. `tauri-plugin-positioner` mixed them: it took the tray rectangle (scale 2, `x = 2146`) and set it as a physical position for a window created on the external display (scale 1), so the window went to `x = 1990` points while the built-in display is 1512 points wide. Off every display, `NSWindow.screen` is `nil`, so `current_monitor()` is `None` and the plugin failed on every later click. A new window goes to the display that has the keyboard focus (`NSWindow.center()`), hence the launch-to-launch difference.

**Fix.** Work in logical points, the unit AppKit places windows in: divide each monitor by its own scale (`windows::logical_rect`), the cursor by the primary monitor's (`windows::pointer_in_points`), and the tray rectangle by the scale of the display under the pointer (the pointer is on the icon when it is clicked). Place with `set_position(LogicalPosition…)`. See `windows::popover_placement` (TAD-032), built like the Quick Panel's placement (TAD-006).

**How to avoid it.** Never pass a physical position from one source to another; never call `set_position` with a `PhysicalPosition` computed from another window, monitor or tray. Test placement with two displays of different scales, one at a negative origin, and start the app with the focus on each display.
