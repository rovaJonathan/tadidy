## Decisions and notes

Add here, with the date and the ticket (`TAD-xxx`), any decision taken along the way (technical choice, accepted deviation from the prototype or the spec, answer to a `blocked` ticket). One entry per decision, newest first, in English.

- 2026-10-29 · TAD-004 · `SourceApp::new` exists only because the coverage gate fails a changed file with no executable line ("in no report"), and `platform/workspace.rs` held nothing but a struct and a trait. The gate is left as it is (TAD-002 scope); a small tested constructor, like `Representation::new`, gives the file real code. A gate that ignores files with no instrumented line would remove the workaround: to raise with the owner if it comes back.
- 2026-10-29 · TAD-004 · `NsWorkspace::frontmost_app` returns `None` for an app without a bundle identifier (no `Info.plist`): the exclusion list is keyed by bundle id, so such an app cannot be told apart and the watcher treats the copy as having no known source.
- 2026-10-29 · TAD-004 · `objc2*` are macOS-target dependencies with `default-features = false`: the defaults switch on 306 AppKit features and the ticket asks for only the ones used. `libc` is needed by `NSRunningApplication` for `pid_t`. `frontmostApplication` stays stuck on the app the process started in unless the main run loop runs (seen with the first probe: TextEdit was in front, the probe still said Terminal), so the probe polls from a thread and runs the main run loop through `macos/run_loop.rs`, like the watcher inside Tauri. The watcher (TAD-010) must not run on a process without that loop.
- 2026-10-28 · TAD-003 · The popover shows and hides through a `PopoverWindow` trait (`windows.rs`), tested with a fake: Tauri's mock runtime ignores `show` and `hide` and `is_visible` is always `true`, so a test on a mock window cannot see either. The real window implements the trait; showing it for real is manual QA.
- 2026-10-28 · TAD-003 · The native tray (`build_menu`, `setup`) is in `src-tauri/src/macos/tray.rs`, not in `tray.rs` as the ticket's *Files* said: muda only creates an `NSMenu` on the main thread and unit tests run on worker threads (it panics), so `tray.rs` sat at 70 % under the gate. `tray.rs` keeps the tested logic: `menu_items`, `menu_action`, `toggles_the_popover`. AGENTS.md §9 exception, covered by manual QA `### TAD-003`.
- 2026-10-28 · TAD-003 · `tauri-plugin-positioner` is on 2.4.0, the newest 2.x: crates.io's latest is `3.0.0-alpha.3` (a Tauri 3 pre-release, forbidden by AGENTS.md §2). Plugin versions are independent of the `tauri` minor, so the "same minor" rule is read as "same major". `window-vibrancy` is 0.8.1.
- 2026-10-28 · TAD-003 · `Esc` is handled in `Popover.svelte` (`<svelte:window onkeydown>`), not in `src/lib/keyboard.ts` (AGENTS.md §14): that module does not exist yet and a popover with one key does not justify it. TAD-016 brings the real keyboard handling and moves it there.
- 2026-10-28 · TAD-003 · `popover.ts` sets `data-theme` from `prefers-color-scheme` (DESIGN.md §2: follows the system by default); the override from Preferences › Appearance comes with the Preferences ticket. The capability `default.json` now lists `popover` instead of `*` (minimum grant, AGENTS.md §2).
- 2026-10-28 · TAD-003 · The tray icon embeds the 36 × 36 px (@2x) template: macOS scales a template image to the menu bar's 18 pt height, so the larger file stays sharp on Retina; `tray-template.png` (@1x) is kept as the ticket asks. The glyph (a clipboard) is a first drawing, to be replaced when the brand icon exists.
- 2026-10-28 · TAD-021 · An `in-progress` ticket whose branch is checked out (main folder or worktree) is owned by another session: `tadidy-session` never proposes it and moves on to the next ticket; the human resumes it by naming it. A ticket `done` or `canceled` on `main` wins over a stale local branch.
- 2026-10-28 · TAD-002 · The coverage gate excludes `src-tauri/src/lib.rs` (decided with the owner): it only holds module declarations and the Tauri builder, which run when the app starts and no unit test reaches (0/16 lines), while most tickets modify it. Rule: no logic in `lib.rs`; anything testable goes in a tested module.
- 2026-10-28 · TAD-002 · The coverage gate (`scripts/coverage-changed.mjs`) also excludes the dev harness `src/main.ts` and `src/App.svelte`, beyond the ticket's list: TAD-001 left them out of the Vitest report (covered by `e2e/`), so any change to them would have counted as 0 %.
- 2026-10-28 · TAD-001 · `scripts/check.sh` unsets `SDKROOT`: `/usr/bin/git` exports the Command Line Tools SDK to hooks, which broke linking in `pre-push` when Xcode is older than the Command Line Tools ([solution](docs/solutions/build/2026-10-28-sdkroot-from-git-breaks-linking-in-hooks.md)).
- 2026-10-28 · TAD-001 · TypeScript is on 6.0.3, not 7.0.2: `typescript-eslint` 8.72.1 requires `<6.1.0` and `svelte-check` 4.7.7 `^5 || ^6`. Move to 7 once both accept it (AGENTS.md §6: newest major the toolchain accepts).
- 2026-10-28 · TAD-001 · pnpm stays on the 10 line (10.34.9) although npm's `latest` is 12.x: AGENTS.md §6 fixes pnpm 10; a jump needs an ADR. `@types/node` follows the 24 line to match Node 24 LTS.
- 2026-10-28 · TAD-001 · `.cargo/config.toml` (sets `TS_RS_EXPORT_DIR`) lives at the repo root, not in `src-tauri/.cargo/` as the ticket said: cargo reads config from the working directory and its parents, never from `--manifest-path`, so `cargo test --manifest-path src-tauri/Cargo.toml` from the root wrote the bindings to `src-tauri/bindings/`.
